# Keyboard and accessibility

Everything in Curvis works from the keyboard. Every command is in the menus, and most
have a shortcut. On a Mac, use Cmd where this page says Ctrl.

## The command palette

**Ctrl+K** opens the command palette: type a few letters of what you want to do
("export", "group", "next pane") and press Enter. It lists every command of the menus and
toolbars, with its shortcut.

## Moving around the main window

| Keys | Does |
| --- | --- |
| F6 / Shift+F6 | Move to the next / previous pane: the table, the Results or Graph panel, and the table tabs |
| Arrow keys, Page Up, Page Down | Move in the table |
| Tab / Shift+Tab | In the table: the next / previous cell (Tab in the last column adds a column). In a panel or dialog: the next / previous control |
| Ctrl+Page Down / Ctrl+Page Up | Next / previous table |
| Typing | Starts editing the current cell; Enter, Tab or an arrow key keeps the value and moves on |
| Enter / Shift+Enter | Move down / up |
| F2 | Edit the text of the current cell in place (the arrow keys then move the text cursor) |
| Delete, Backspace | Clear the selected cells |
| Esc | Leave a cell or a header name without changing it; close a dialog |

Tab moves between cells inside the table, so F6 is the way from the table to the
panel next to it and back. **View › Next pane** and **Previous pane** do the same.

## In dialogs

- Tab follows the reading order: the tabs across the top, the left column, the right
  column, then the buttons.
- Ctrl+Tab and Ctrl+Shift+Tab move between the tabs across the top of a dialog.
- An underlined letter in a label (Alt+letter on Windows and Linux) jumps to its field.
- Enter runs the main button (Run, Apply, Import), Esc cancels, and Space ticks the check
  box or list item that has the focus.

## Screen readers and contrast

Every control has a name that screen readers read out, the table included ("Table" and
its name). Both themes give text at least 4.5 : 1 contrast with its background, and
outlines, focus marks and the selection at least 3 : 1. **Settings › General › Theme**
switches between light and dark, or follows the system.
