Curvis table tabs

A project holds several tables, each in its own tab inside the project tab. The Results and Graph panels stay at the right and show the analyses and graphs of the table that is selected. Orange numbers point to the notes.

1 · Main window: table tabs along the bottom

  1. Table tabs sit under the table and the side panel, as in a spreadsheet. The selected tab joins the table above it. The Results and Graph panels show the analyses and graphs of the selected table.
  2. + at the end of the row is New table (Ctrl+Shift+N). There is no toolbar button for it; the + is always visible.
  3. Each tab has a close button. Closing deletes the table, after a warning (board 3).

Import data, Add column, Calculate, Plot and Analyze act on the selected table.

2 · New table in the File menu (Ctrl+Shift+N)

  1. New table in the File menu, right under New project, with Ctrl+Shift+N (not used yet, and not a platform standard key). It is also in the command palette.
  2. Close table… asks first (board 3). Ctrl+W keeps closing the project; its menu text becomes “Close project” so the two are told apart.

The new table is named “Table 2”, “Table 3” …, added after the selected tab and selected. One undo step.

Import data always goes into the selected table. The status bar names it: “Imported 96 rows and 4 columns from plate.csv into Viability.”

3 · Closing a table deletes it, after a warning

  1. Window title names the task: “Close table”. The first line says what happens to what.
  2. What else goes with it: its analyses and graphs (they belong to the table). A table with nothing attached gets only the first line.
  3. Undo is one step (Ctrl+Z), and is said, so the warning does not feel final.
  4. The verb button is Delete table. Cancel has the default focus, so Enter does not delete by accident.

Closing an empty table (no data, no analyses, no graphs) does not ask.

Formulas read only columns of their own table, so the table's calculated columns go with it. A calculated column whose source column is gone shows its error (⚠ in the header, “Unknown column …”), as it does today when a column is deleted.

4 · Tab menu and renaming

  1. Double-click a tab to rename it in place. Enter keeps the name, Esc cancels. A name that is taken shows a message in the status bar and keeps the old name.
  2. Right-click: Rename, Close table…, New table. Tabs can be dragged to change their order.
  3. Ctrl+Page Down and Ctrl+Page Up go to the next and previous table (as in spreadsheets); Ctrl+Tab stays for the choice tabs in dialogs.

5 · The last table cannot be closed

  1. A project always has at least one table. With one table left, its tab has no close button.
  2. Close table… is disabled, and says why: “A project needs at least one table.” (DESIGN.md: a disabled action always says why.)

A new project starts with one blank table, as now. A project file without tables opens with one blank table added.
