1 · Graph panel, 460 px wide (Format graph hovered)

1
GraphXY graph · Dose response
Format graph (Ctrl+Shift+F)
  1. Where: at the right of the panel header, after the graph list. Icons only, like the main toolbar: 28 px buttons, 4 px apart, no text. The graph list takes the rest of the width.
  2. Order: Change graph type, Format graph, Delete graph, Export graph. Each is the registered action (Graph menu and command palette too); the tooltip gives name and shortcut.
  3. Shortcuts: Format graph Ctrl+Shift+F, Export graph Ctrl+Shift+X (reserved in §6). Change graph type and Delete graph: menu and palette only.
  4. The graph is the export page zoomed to fit (here Wide, 9 × 6 cm): text, symbols and lines scale with the panel. Double-click opens Format graph.
