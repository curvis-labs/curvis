Changes

  1. A grouped list replaces the radio grid. The sub-families from SPEC.md become section headers (Linear, Dose-response, Kinetics, Shape-based; for tests Describe, Two groups, Three or more groups), with recently used analyses in a Recent section on top instead of a “recent” badge. Each row says in a few words what the analysis reports. Only analyses the table supports are listed, as now.
  2. Filter field above the list. Typing “ec50” or “decay” narrows the list to matching names and descriptions; arrow keys move through it and Enter runs.
  3. The list scrolls after about six rows, so the dialog keeps its 900 × 640 size (DESIGN.md) with Advanced open. Sections can be collapsed.
  4. Options move to the left column, under the data. What to analyze and how (series, X range, fixed values) now sit in one column; the right column is about the chosen analysis.
  5. The X range is two number fields directly under the log checkbox, out of Advanced. Empty means no limit; the count of points used updates as you type. Replaces the text field “Fit only X from … to … (empty: all)”.
  6. Fix parameters becomes a table in Advanced: one row per model parameter with a Fix checkbox and a value. Names come from the model, so nothing has to be typed or spelled right. The last free parameter can't be unticked. Replaces the text field “Fix parameters (e.g. bottom = 0)”.
  7. “About this analysis” replaces “What will run”. One panel for the chosen analysis: the equation (fits) or the hypothesis (tests), then the sentence that says what will run, as now.
  8. Sketch of the model with its parameters marked. A fixed parameter is drawn in the accent colour with its value and updates as you tick Fix. It is a fixed drawing per model, not a fit of the data, so it costs no computation.
  9. A “use when” line in plain language, pointing to the alternative where there is one (e.g. Kruskal-Wallis for skewed data).
  10. Tests show the null hypothesis and assumptions in place of the equation and sketch.

Stays the same: the family tabs, the data list, the Run/Cancel row and feedback line, the stored parameters ("top = 100", "-9 to -5") and so every saved project. Needs a small edit to DESIGN.md (the right column has no “What will run” box any more) and to SPEC.md (the equation, sketch and use-when text per analysis).
