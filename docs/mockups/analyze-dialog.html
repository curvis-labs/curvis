  1. A grouped list replaces the radio grid. The sub-families from SPEC.md (Linear, Dose-response, Kinetics, Shape-based) become section headers, with recently used analyses on top. Each row says in a few words what the analysis reports.
  2. Filter field. Type “ec50” or “decay” to narrow the list; arrow keys move, Enter runs. Long sections can be collapsed (▾).
  3. Options on the left, under the data. Choosing what to fit (data, X range, fixed values) sits in one column. The X range is two number fields directly under the log checkbox; empty means no limit, with a live count of the points used.
  4. Fix parameters becomes a table in Advanced. The parameter names come from the model, so nothing has to be typed or spelled right. Ticking Fix enables the value field; the last free parameter can't be unticked.
  5. One panel for the model and what will run: the equation, a sketch of the curve with its parameters marked (a fixed one in the accent colour with its value; it updates as you tick Fix), the sentence that says what will run, and when to use the model. For tests (Compare groups) the sketch is replaced by the null hypothesis and assumptions, e.g. “H₀: all group means are equal. Assumes normal data with equal SDs.”

The sketch is a fixed drawing per model (an SVG icon, with labels), not a fit of your data, so it costs no computation and stays within the spec.

Effort: smallest change. Uses only QListView/QTreeView and stock widgets; the stored strings ("top = 100", "-9 to -5") and saved projects stay as they are.

Compare groups would show the same list with sections Describe, Two groups, Three or more groups.

  1. A gallery of curve shapes. Each model is a card with a thumbnail of its shape, grouped by sub-family. People recognise “rises and levels off” faster than they remember a model's name. Arrow keys move between cards.
  2. The equation of the selected model sits under the gallery, so it's clear what will be fitted before Run.
  3. Parameter chips. Click a chip to switch it between fit and fixed at … (a small pop-up with one number field).
  4. X range on a preview of the data. Drag the two handles over the points of the ticked series, or type in From/To. Points outside the range are dimmed.

Effort: the largest. The thumbnails are static icons, but the range preview is a small pyqtgraph plot inside the dialog, which goes beyond the spec (needs a SPEC/DESIGN change and a benchmark for opening the dialog). Without the preview, the From/To fields from version A remain.

Compare groups fits a gallery less well: it would fall back to the list of version A.

  1. One drop-down instead of a list. The dialog opens with a sensible analysis already chosen, so the 11 options stay out of sight until you ask for them (shown opened below the dialog).
  2. Search inside the drop-down matches names and what they report (“ec5” finds every model with an EC50). Suggestion chips under it: the best fit for the data plus recently used ones, one click each.
  3. The parameters are always visible with a Fit / Fix switch per parameter. Fixing a parameter is common for dose-response fits, so it moves out of Advanced; nothing to type except the value.
  4. Points: All / X range as a switch, with From/To drop-downs of the X values only when needed. Advanced keeps the rare options.

Effort: medium. A searchable QComboBox with a custom popup view; the rest are stock widgets. Moving Fix parameters out of Advanced is a change to the DESIGN rule that the common case needs no options; it stays one click on Run.

Compare groups would use the same drop-down, with suggestions like “One-way ANOVA (4 groups ticked)”.
