  1. Families as tabs. Only families the table supports are shown (Survival is hidden here because there are no time/event pairs). The dialog opens on the best-fitting family (SPEC.md).
  2. Inputs on the left: the same column tree and pairing toggle as Calculate, so paired tests reuse the A/B pairing.
  3. Analysis and options on the right. The analysis list shows only what can_run allows, recently used ones are marked, and the options panel takes the height of the selected analysis's page.
  4. Result: one plain sentence that says what will run, with exact method names.
  5. Advanced is collapsed, e.g. confidence level. One click on Run covers the common case.
  6. Feedback line: a warning (icon + normal text). When Run is disabled, the reason appears here, e.g. “Tick at least two groups.”

Button order follows the platform; shown here as on Windows and KDE.

  1. Sections as tabs: Graph, Axes, Series, Colors and text, following SPEC.md's list of Format controls.
  2. Inputs on the left: the items to format. Axes lists X and Y. Series lists the series and allows several to be selected at once.
