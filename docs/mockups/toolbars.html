  1. Main toolbar: New project, Open project, Save project | Undo, Redo. Icons only; the tooltip gives name and shortcut.
  2. Table toolbar, shown while a table is shown: Import data | Add column, Group as replicates, Set category, Calculate | Plot, Analyze. Icon with text, because these are Curvis's own tasks.
  3. Plot has a menu arrow: it opens the chart families (see 2). Analyze opens the Analyze dialog.
  4. Disabled buttons use the disabled colour, and their tooltip says why. Hover shows a soft square.

Every button is the same action as its menu item and command palette entry. The toolbars are fixed in place and not in the Tab order.

This menu is SPEC.md's “pick a chart family from the toolbar”: it makes a graph of that family from the table, and the Format dialog picks the variant (scatter or line, box, violin …).

A family the table cannot draw stays in the list, disabled, with the reason beside it, so users learn what each needs.
