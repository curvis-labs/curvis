Curvis launcher

The start screen, shown when no project is open: a blank project and the sample projects as tiles, Open project…, and recent projects with relative times. Orange numbers point to the notes.

1 · Launcher with recent projects

  1. A row of tiles: Blank project first, then the sample projects, each with a small picture of its graph (the samples come with step 2.9). Click a tile to start; a sample opens as a new, untitled copy.
  2. Open project… sits at the right of the Recent projects heading, next to the list it belongs with.
  3. Recent projects, newest first: name, folder (shortened in the middle when long) and when it was last opened. One click opens. The hovered row is shaded.
  4. Right-click a row: Open, Remove from list. Removing never touches the file. A missing file is dimmed and says “File not found”; clicking it does nothing.

No logo, version or tagline: the window title already says Curvis, and the page is about starting work.

The column is 760 px wide and centred; in a narrower window it fills the width with the 12 px margin, and the tiles that do not fit wrap to a second row.

2 · First start and before the samples exist (shown smaller)

First start: no recent projects
Until step 2.9: Blank project only

With no recent projects the list is replaced by one centred sentence (DESIGN.md section 5): “Projects you open or save will appear here.” The launcher shows no key combinations. Keyboard: Blank project has the focus, so Enter starts one; Ctrl+N and Ctrl+O work as everywhere. Tab moves from the tiles to Open project… and the list; arrow keys move along the tiles and in the list, Enter opens, and the menu key or Shift+F10 opens the row's menu.
