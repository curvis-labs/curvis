Curvis launcher

Three versions of the start screen, shown when no project is open: New project, Open, recent projects with relative times, and the sample projects planned for step 2.8. Board 4 shows each one on first start. Orange numbers point to the notes.

A · Centred welcome: two action tiles, recent projects under them

  1. Logo, name and one line on what Curvis does. Calm and centred, 620 px wide at any window size.
  2. Two large tiles: New project and Open project…, each with its shortcut. New project has the focus, so Enter starts one.
  3. Recent projects as a list of rows: name, folder (shortened in the middle when long), and when it was last opened at the right. One click opens. The hovered row is shaded.
  4. A missing file is dimmed, says “File not found” and offers Remove.
  5. Sample projects as plain links in one line at the bottom (step 2.8).

Simple, looks finished, works the same at any width.

The samples are easy to overlook.

B · Side panel with actions, recent projects as a full-height table

  1. A panel at the left holds the logo, the version and the actions as stacked buttons. New project is the filled (primary) button.
  2. Sample projects as links under their own heading.
  3. Recent projects fill the rest as a table: name, folder, last opened. The folder column is what tells two files with the same name apart.
  4. Right-click a row: Open, Remove from list. A missing file shows “File not found” in the last column.

Familiar from IDEs; the list gets the most room, good for people with many projects.

More like a tool than a welcome; a bit busy for the first start (board 4).

C · Start gallery: a blank project and the samples as tiles, recent projects below

  1. A row of tiles: Blank project first (with its shortcut), then the three sample projects, each with a small picture of its graph.
  2. Open project… sits at the right of the Recent heading, next to the list it belongs with.
  3. Recent projects as in A.

Shows at a glance what Curvis makes; the samples invite a first try, which helps new users most.

The tiles use height that the recent list could use. Needs the sample projects (step 2.8) to look complete; until then only Blank project shows.
