# Launcher icons

`project_file.svg`: the file icon in front of each recent project (docs/DESIGN.md,
section 10), drawn at 28 × 28. Like the toolbar icons it uses two colours that the
launcher replaces with palette colours: `#1d3557` (the page) becomes `PlaceholderText`
and `#00a6a6` (the data) becomes `Link`. For a missing file both use the disabled text
colour.
